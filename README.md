# 🏸 羽毛球业余选人系统

一个用于羽毛球业余娱乐比赛分队选人的单文件网页工具。适用于俱乐部活动、球友约战等场景，让分队过程公开、透明、有仪式感。

## 功能特性

- **等级体系**：采用中羽等级 0.5 ~ 4.5（步长 0.5），等级徽章按高低配色显示
- **队长选人**：先设定各队队长，剩余已定级选手由队长轮流挑选
- **每队 5 人**（含队长），队伍数量支持 2 ~ 6 队
- **首轮顺序**：随机抽签决定
- **后续轮次**：每轮选完后，由**总等级最低**的队伍先选（平级时人数多的队先选），保证各队实力均衡
- **实时显示**：当前轮次 / 总轮次 / 剩余轮次、各队总等级与阵容
- **操作日志**：记录每轮选人顺序与结果
- **撤销功能**：支持撤销上一步选人（自动恢复正确的轮次顺序）
- **结果导出**：一键复制最终分队结果文本

## 快速开始

无需安装任何环境，两种方式任选其一：

### 方式一：直接打开（推荐）

1. 下载本项目中的 `draft.html` 文件
2. 用浏览器（Chrome / Edge / Firefox 等）直接双击打开即可使用

### 方式二：本地服务器

```bash
# 在项目目录下任选一种方式
python -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000/draft.html`

### 在线体验（可选）

可将仓库开启 GitHub Pages / Gitee Pages，直接在线使用：

- GitHub：Settings → Pages → 选择 main 分支 → 保存后访问 `https://<用户名>.github.io/<仓库名>/draft.html`

## 使用流程

1. **设置队伍**：选择队伍数量，填写各队队长姓名与等级（可自定义队名）
2. **录入选手**：添加已定级的待选选手（数量 = 队数 × 4），或点击"示例数据"快速体验
3. **开始选人**：点击"开始选人"，系统随机抽签首轮顺序
4. **轮流挑选**：按顶部横幅提示，轮到的队长点击选手池中的选手选入本队
5. **自动轮转**：每轮结束后自动按"总等级最低先选"重排顺序
6. **完成导出**：全部选完后，一键复制结果发到球友群

## 选人规则说明

| 项目 | 规则 |
|---|---|
| 每队人数 | 5 人（1 队长 + 4 队员） |
| 首轮顺序 | 随机抽签 |
| 后续轮顺序 | 各队总等级升序（最低者先选；平级时人数多者优先） |
| 满员处理 | 已满员的队伍自动跳过 |
| 结束条件 | 所有队伍满员 |

> 通过"总等级最低先选"的补强机制，弱队总能优先挑选高等级选手，使各队最终总等级趋于接近。
